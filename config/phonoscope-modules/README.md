# Phonoscope reference modules

These directories are authoring examples and conformance fixtures. Validate one
with `npm run phonoscope:validate -- config/phonoscope-modules/<name>/module.yaml`
or package it with `npm run phonoscope:pack -- config/phonoscope-modules/<name>`.

The dashboard's permanent offline fallback (`bpm-pulse`) is compiled into the
service. The examples can be uploaded through Configuration → Appearance &
Dashboard → Phonoscope.
